# Daybook

A lightweight to-do list that stores your tasks in this browser's Local Storage. No account or server is required.

## Run it

Open `index.html` in a modern browser. Tasks stay on this device and in this browser; clearing browser site data will remove them.

## Features

- Add, edit, complete, and delete tasks
- Set a due date and priority
- Browse all, today's, upcoming, or completed tasks
- Search and sort your list
- Track completion of tasks due today

Task data is stored under the `daybook.tasks.v1` Local Storage key.
